# Reproducibility manifest

Every physical run must record:
- Git commit and dirty/clean state;
- configuration SHA-256;
- firmware and radar serial identifiers;
- anchor coordinates and calibration version;
- challenge codebook;
- synchronization measurements;
- attacker class, hardware, placement, power, and latency;
- non-identifying scenario/participant code;
- UTC start/end time;
- output file checksums;
- failures, exclusions, and operator interventions.
